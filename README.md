# 📊 Customer Behaviour Analysis

## 📌 Project Overview
This end-to-end Data Analytics project analyzes customer purchasing behaviour using SQL Server, Python, and Power BI to uncover business insights and support data-driven decision making.

## 🎯 Business Problem
The company wants to understand:
- Who are the most valuable customers?
- Which products generate the highest revenue?
- How frequently do customers purchase?
- What factors influence customer behaviour?

## 🛠️ Tools & Technologies
- SQL Server
- Python (Pandas, NumPy, Matplotlib)
- Jupyter Notebook
- Power BI
- Excel

## 📂 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. SQL Analysis
5. Power BI Dashboard
6. Business Insights & Recommendations

## 📈 Key KPIs
- Total Revenue
- Total Customers
- Average Order Value
- Purchase Frequency
- Customer Segments
- Top Products

## 💡 Business Insights
- Identified high-value customer segments.
- Analyzed purchasing patterns across categories.
- Measured customer frequency and revenue contribution.
- Recommended strategies to improve customer retention.
