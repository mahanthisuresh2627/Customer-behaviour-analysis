# SQL Analysis

This file contains business-oriented SQL queries used to analyze customer purchasing behaviour.

## Business Questions Solved

1. Revenue generated by male vs female customers
2. Customers using discounts with above-average spending
3. Top 5 products by average review rating
4. Purchase amount comparison by shipping type
5. Subscriber vs non-subscriber spending analysis
6. Products with highest discount usage
7. Customer segmentation (New, Returning, Loyal)
8. Top 3 products within each category using Window Functions
9. Repeat buyers and subscription analysis
10. Revenue contribution by age group

## SQL Concepts Used

- GROUP BY
- CASE WHEN
- CTEs
- Window Functions (ROW_NUMBER)
- Aggregate Functions
- Filtering and Sorting
